# Glossário

**Device:** equipamento gerenciado.

**NetworkInterface:** interface de rede.

**SwitchPort:** porta física/lógica de switch.

**Discovery:** processo de descobrir equipamentos e relações.

**MonitoringCheck:** definição do que será monitorado.

**MonitoringResult:** resultado de uma verificação.

**Alert:** condição detectada.

**Incident:** agrupamento operacional de problema.

**Task:** unidade de trabalho.

**SLA:** compromisso de serviço.

**SLO:** objetivo mensurável.

**Outbox:** mensagens persistidas na mesma transação dos dados.

**DLQ:** fila de mensagens que falharam após política de retry.

**Envelope:** estrutura de transporte com metadados do evento.

**CorrelationId:** identifica uma cadeia de operação.

**CausationId:** identifica a causa de uma operação/evento.

**Idempotência:** executar novamente sem produzir efeitos duplicados.

**RBAC:** controle por papéis.

**ADR:** Architecture Decision Record.

**TDD:** Test Driven Development.
