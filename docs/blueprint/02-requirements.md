# Requirements

## Funcionais

- inventário;
- descoberta;
- monitoramento;
- alertas;
- incidentes;
- tasks;
- SLA/SLO;
- notificações;
- identidade;
- auditoria;
- acesso remoto.

## Não funcionais

- on-premises;
- segurança;
- auditabilidade;
- observabilidade;
- tolerância a falhas;
- execução incremental.
