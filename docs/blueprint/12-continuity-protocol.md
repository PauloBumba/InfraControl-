# Continuity Protocol

Ao iniciar uma sessão:

1. Ler README.
2. Ler AGENTS.
3. Ler PROJECT_STATE.
4. Ler TASKS.
5. Ler ADRs relevantes.
6. Identificar Task.
7. Verificar dependências.
8. Dividir se necessário.
9. Executar uma pequena parte.
10. Testar.
11. Atualizar estado.

Isso permite continuidade entre sessões de IA.
