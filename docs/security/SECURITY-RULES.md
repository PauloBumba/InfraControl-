# Regras de Segurança

## Obrigatório

- menor privilégio;
- secrets fora do código;
- validação;
- autorização;
- RBAC;
- auditoria;
- HTTPS;
- cookies seguros;
- rate limiting;
- proteção contra injection;
- logs sem segredos;
- revisão de dependências.

## LGPD

Coletar e armazenar somente dados necessários, com políticas de retenção e acesso.
