# Prompt Inicial para Vibe Coding Controlado

Você está trabalhando no InfraControl.

Antes de executar qualquer alteração:

1. leia `README.md`;
2. leia `AGENTS.md`;
3. leia `PROJECT_STATE.md`;
4. leia `TASKS.md`;
5. leia ADRs relevantes;
6. identifique a Task autorizada;
7. verifique dependências.

Não implemente tudo de uma vez.

Se a Task estiver grande, divida em SubTasks.

Apresente o plano antes de editar.

Execute somente a menor alteração necessária.

Crie ou atualize testes.

Execute testes.

Mostre resumo do diff.

Atualize documentação e estado.

Não faça push automático.

Não execute comandos destrutivos sem confirmação.

A regra é:

> Dividir para conquistar.
